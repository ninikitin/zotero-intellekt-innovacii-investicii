# Стиль Zotero «Интеллект. Инновации. Инвестиции» (раздел «Литература»)

Файл стиля: **`intellekt-innovacii-investicii.csl`**
Числовой стиль по ГОСТ Р 7.0.5-2008: ссылки в тексте — `[N]`, список «Литература» — по алфавиту.

## Установка

1. Zotero → **Настройки → Cite → Styles**.
2. Кнопка **«+»** → выберите файл `intellekt-innovacii-investicii.csl`.
3. В списке появится **«Интеллект. Инновации. Инвестиции (Russian)»** — выберите его в документе Word/LibreOffice через плагин Zotero.

## Ссылки в тексте

- Один источник: `[5]`
- Со страницей: `[9, с. 14]` (в окне вставки ссылки укажите локатор «Страница» = 14)
- Несколько источников: `[5; 9; 12]` — разделитель точка с запятой

Номер `[N]` — это позиция источника в списке «Литература». Список сортируется по алфавиту, поэтому номера присваиваются по алфавитному порядку.

## Заполнение полей в Zotero

Три элемента выводятся из конкретных полей — заполняйте их так:

| Что нужно | Поле Zotero | Как заполнять | Результат в списке |
|---|---|---|---|
| **DOI** | «DOI» | только номер: `10.25198/2077-7175-2020-5-10` | `– https://doi.org/10.25198/...` |
| **EDN** | **«Loc. in archive»** | только код: `RVRMXQ` | `– EDN: RVRMXQ.` |
| **Дата обращения** | «Accessed» + «URL» | обычным образом | `– URL: ... (дата обращения: 04.06.2018).` |

Ещё несколько правил заполнения:

- **Диссертация, патент и т. п.**: тип документа берётся из поля **«Type»** (напр. `дис. … канд. экон. наук`) → выводится как `: дис. … канд. экон. наук`.
- **«: монография»** у книг впишите прямо в конец **заглавия** — отдельного поля для этого у типа «Книга» нет.
- **Не ставьте точку в конце заглавий** и названий журналов/сайтов — стиль сам расставляет точки между областями.
- **URL** выводится для любой записи, где заполнено поле «URL». Если у печатного источника URL не нужен, очистите это поле.

## Оформление списка (красная строка 1.25 см)

Между номером и текстом стоит пробел (`1. Иванов И. И. …`), tab и висячий отступ убраны. Отступ первой строки задаётся один раз в текстовом редакторе через стиль абзаца «Список литературы / Bibliography» и сохраняется при обновлении списка.

**Microsoft Word:** щёлкните внутри списка → найдите стиль абзаца **«Список литературы»** → правой кнопкой → **«Изменить…» → «Формат» → «Абзац…»**: Отступ слева = `0 см`, Первая строка → **Отступ** = `1.25 см` (без «Выступа»).

**LibreOffice Writer:** выделите список → **Формат → Абзац → «Отступы и интервалы»**: Перед текстом = `0 см`, Первая строка = `1.25 см`.

## Сортировка

Список сортируется по алфавиту (по автору, затем по заглавию). Иностранные (латиница) источники оказываются в конце. Если в вашей версии Zotero латиница встала иначе, переставьте эти записи в конец вручную в документе.

## Работы с 4 и более авторами

Стиль указывает авторов в начале описания с добавлением `[и др.]` (`Иванов И. И. [и др.] Заглавие …`). Если по требованиям нужен вынос авторов после заглавия, поправьте такие записи (обычно единичные) вручную.

## Разделитель ссылок (по желанию)

По умолчанию несколько ссылок выводятся списком через «; ». Чтобы подряд идущие номера сворачивались в диапазон (`[3; 4; 5]` → `[3–5]`), откройте `.csl` в текстовом редакторе и в строке

```xml
<citation delimiter-precedes-et-al="never">
```

добавьте атрибут `collapse="citation-number"`:

```xml
<citation delimiter-precedes-et-al="never" collapse="citation-number">
```

Затем переустановите стиль в Zotero.
